# OpenRGB

Open source RGB lighting control that doesn't depend on manufacturer software. Official Flatpak build maintained by the OpenRGB developers.  Check out the OpenRGB website at [openrgb.org](https://openrgb.org).

## Flatpak Notes

* OpenRGB requires special permissions to access and control RGB hardware devices.  If you're running OpenRGB as your normal user account, you will need to configure udev rules in order for OpenRGB to access devices.  Starting with OpenRGB 1.0, the udev rules are generated by OpenRGB rather than provided as a separate download.  Instructions for generating and installing the udev rules can be found at https://openrgb.org/udev.
* The OpenRGB Flatpak now has host and host-etc read-only permissions.  This is to allow it to check for the existence of udev rules in both /etc and /usr paths.  OpenRGB will display a warning if the udev rules are missing or if there are udev rules installed in both locations at the same time.
* Some devices will require additional permissions not granted automatically.  If you're using a device that needs access to /sys/class/leds such as Valve's Steam Machine, you will need to grant --filesystem=/sys permissions manually.
* Other devices may not be controllable at all using the Flatpak installation due to sandboxing.  This is the case for devices with more restricted transports like NVMe and Super IO interfaces.  If you have a setup with these devices, it is recommended to use the AppImage version or a distribution package instead of the Flatpak.
